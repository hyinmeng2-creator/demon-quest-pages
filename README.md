# Demon Quest for GitHub Pages

Publish the `docs/` folder from the `main` branch in GitHub Pages.

- `docs/grammar/` and `docs/vocabulary/` are standalone modules.
- Each module contains its own HTML, CSS, JavaScript, and 24-item question bank.
- Progress is anonymous and stored in the browser separately for each module.
- No Python server or API key is needed.

Upload this repository with the `docs/` structure intact. Do not add local Python environments, API keys, or `.env` files.
